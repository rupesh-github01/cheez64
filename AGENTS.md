# Project instructions

## Segment plans and reports

- Save every segment architecture plan and implementation/validation report in `plan_report/`.
- This folder is intentionally Git-ignored. Keep its ignore rule and never stage or commit its contents.
- Read existing documents there when researching previous architecture, decisions and measurements. Their absence from Git history is expected, not a documentation or audit gap.
- Preserve previous documents. Do not overwrite them without explicit user authorization or fabricate/reconstruct measurements when the originals exist.
- If a segment document exists at the repository root, check for existing destination copies before relocating it into `plan_report/`; preserve all content and resolve conflicts without data loss.
